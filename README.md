## 🎯 Why This Repository?

This repository represents an unbroken journey of competitive programming and algorithmic problem-solving. It is not just a dump of code, but a structured log of mastering **Data Structures & Algorithms (DSA)** through daily practice. 

As a recruiter or engineering manager, here is what this repository demonstrates:
- **Consistency & Discipline**: Over 2000+ solutions pushed regularly, representing a dedicated daily habit of coding.
- **Java Proficiency**: All code is strictly authored in Java, demonstrating a strong grasp of Object-Oriented Programming, Java Collections Framework (JCF), and language-specific optimizations.
- **Algorithmic Depth**: Solutions range from simple array manipulation to advanced dynamic programming, graph theory, and bit manipulation.
- **Clean Code Practices**: Emphasizes readable code, proper naming conventions, and handling of edge cases.

## 📂 Repository Structure

The repository is organized by platform. Each directory contains hundreds of solved problems, strictly categorized and named for easy navigation.

| Platform | Directory | Description |
| :--- | :--- | :--- |
| **LeetCode** | [`/LeetCode`](./LeetCode) | Contains optimized solutions for LeetCode problems ranging from Easy to Hard. Focus on Time/Space complexity. |
| **GeeksforGeeks** | [`/GeeksforGeeks`](./GeeksforGeeks) | Solutions for GFG practice problems, heavily focused on core Data Structures. |
| **Codeforces** | [`/Codeforces`](./Codeforces) | Solutions for competitive programming rounds focusing on math, logic, and speed. |
| **CodeChef** | [`/CodeChef`](./CodeChef) | Problem-solving for CodeChef contests and practice sections. |

### 🔍 File Naming Convention
To make the codebase easily searchable, files are named using the following convention:
`ProblemName_Difficulty.java` *(e.g., `BinaryTreeLevelOrderTraversal_Medium.java`)*
